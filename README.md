## 📊 What This Is

Botswana Economic Pulse is a self-updating BI platform that:
- Fetches economic data from multiple sources daily
- Stores it in a PostgreSQL database
- Visualises it on a real-time dashboard
- Generates plain-English insights
- Sends WhatsApp summaries to subscribers

**Built by Theo Anold Gaopalelwe Bida** — Full-Stack Developer & Data Analyst, Gaborone, Botswana.

---

## 🎯 Features

- 📈 **Live currency tracker** — BWP vs USD, ZAR, EUR, GBP
- ⛽ **Fuel price monitoring** — petrol, diesel, paraffin trends
- 📊 **BSE sector performance** — Botswana Stock Exchange
- 🌍 **Country comparison** — Botswana vs regional peers
- 🧠 **Auto-generated insights** — daily plain-English summaries
- 📱 **WhatsApp bot** — morning economic digest
- 🤖 **Fully automated** — GitHub Actions runs everything daily
